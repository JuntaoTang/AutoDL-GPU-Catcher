# AutoDL 抢卡脚本

先在用户工作区定位 `autodl-helper.user.js` 和 `README.md`，使用当前源码；不要用上游旧版覆盖本地修改。按任务需要阅读仓库的 `QUICKSTART.zh-CN.md` 或 `docs/ARCHITECTURE.md`。

## 安装与配置

- 当前名称为“AutoDL 抢卡脚本”。已有“AutoDL 抢卡助手”时，在油猴原条目内替换源码并保存，保留任务与设置；命名空间和存储键不变。
- 用 `INSTALL.html` 复制安装代码；用户已装油猴时优先更新原条目。AutoDL 必须在安装油猴的同一个浏览器内打开，匹配 `https://www.autodl.com/*`。
- 没有入口时，检查当前页面的油猴菜单、用户脚本执行权限，再刷新。若自动操作不可用，提供手动步骤，不声称已安装或已启动。
- 区分实例台数与每台 GPU 张数、实例总 CPU 与每卡 CPU、额外扩容与最终磁盘容量。沿用用户已给出的参数与启动意图，只询问影响配置的缺失项。
- 一个“抢新实例”任务创建一台实例；多个任务各自完成。改表单不会修改已保存任务，先检查已有任务，避免重复添加。
- 价格是折后每卡每小时费用，上下限均包含在区间内；0 表示该端不限，两端相同表示精确匹配。磁盘按日计费，单独展示。
- 默认仅系统桌面通知；用“设置 → 测试提醒”验证。浏览器需保持运行；抢到后实例仍会计费。

## 价格与任务逻辑

- 下单前调用 `/api/v1/order/price/preview`，报价参数与订单 `price_info` 保持相同卡数、扩容和优惠券列表；当前不自动选择优惠券。
- `discount_list` 最后一条 `product_type: instance` 记录的 `origin_price - total_reduction` 是折后 GPU 小时总费，除以卡数后匹配区间；无折扣记录时取预览 `origin_price`。
- 磁盘日费取 `data_disk_info.data_disk_deal_daily_price`。平台金额单位为千分之一元，不把市场 SKU 原价或预览总费误当作折后单卡价。
- 保留创建意图、唯一名称核对及取消后的返回 UUID；结果不明时不重新下单。取消任务不等于关闭或释放实例。
- 安装、测试、查看报价不等于授权付费启动；按用户当前请求执行具体操作，已有授权无需重复询问。

## 维护与验证

保持单文件、直接逻辑和简短说明，不增加无关抽象或防御性分支。保留 `autodl-helper-v1` 存储键与 `version: 1` 格式。

修改后运行：

```bash
npm run build:install
npm run check
npm test
```

涉及界面、API 或任务流程时，再运行 `npm run test:browser`。该测试需要 Playwright 和 Edge，使用模拟接口；不能把模拟通过当作真实付费流程已验证。源码变化后重新生成安装页，并同步名称、版本和文档。
